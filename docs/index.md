# Методичка по Java backend

Практический конспект по Java, Spring, базам данных и проектированию backend-систем. Основной маршрут построен по чек-листу подготовки к собеседованию: от языка и JVM до Kafka, наблюдаемости и system design.

## С чего начать

Если цель — собеседование, откройте [маршрут подготовки](interview/index.md). Он связывает 255 тем в последовательную программу и для каждой главы даёт:

- краткую модель сильного ответа;
- механизмы и ограничения, а не только определения;
- код, SQL и production-примеры;
- типичные follow-up-вопросы;
- задания для самопроверки.

[Начать подготовку →](interview/index.md){ .md-button .md-button--primary }
[Карта покрытия чек-листа](interview/coverage.md){ .md-button }

## Как устроена методичка

| Раздел | Для чего |
|---|---|
| **Подготовка к собеседованию** | Основной последовательный маршрут уровня Java backend |
| **Справочник** | Подробные материалы по синтаксису, SQL, Spring и Hibernate |
| **Практика** | Задачи, домашние работы и проектные упражнения |
| **Дополнительно** | Kotlin/JDBC, web-основы и архитектурные стили |

## Рекомендуемый порядок

1. Java Core, коллекции и generics.
2. JVM и многопоточность.
3. SQL/PostgreSQL, JPA и транзакции.
4. Spring Core, Boot, Web и Security.
5. Kafka, Redis, REST/gRPC и микросервисы.
6. Тестирование, CI/CD и наблюдаемость.
7. System design и практический прогон.

Не отмечайте тему как изученную сразу после чтения. Закрытая тема — та, которую вы можете объяснить за 60–90 секунд, показать небольшим примером и защитить на уточняющих вопросах.
