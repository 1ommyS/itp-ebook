# Массивы в Java

Массив хранит фиксированное число элементов одного типа. Сам массив — объект: у него есть `length`, он может быть передан в метод и может содержать примитивы или ссылки.

## Создание и доступ

```java
int[] scores = new int[3];       // [0, 0, 0]
String[] names = {"Ada", "Linus"};

scores[0] = 10;
int first = scores[0];
int size = scores.length;
```

Индексы лежат в диапазоне от `0` до `length - 1`. Выход за границы приводит к `ArrayIndexOutOfBoundsException`. Размер после создания не меняется; для динамического количества элементов обычно выбирают `ArrayList`.

## Значения по умолчанию

| Тип элемента | Значение |
|---|---|
| Числовой примитив | `0` / `0.0` |
| `boolean` | `false` |
| `char` | `\u0000` |
| Ссылка | `null` |

Локальная переменная-массив должна быть инициализирована до чтения, но элементы созданного массива получают значения по умолчанию.

## Перебор

Индексный `for` нужен, когда важен номер элемента или требуется изменение массива:

```java
for (int i = 0; i < scores.length; i++) {
    scores[i] *= 2;
}
```

Enhanced `for` удобен для чтения:

```java
for (String name : names) {
    System.out.println(name);
}
```

Присваивание переменной `name` не меняет элемент массива: в переменную цикла копируется значение элемента.

## Многомерные массивы

В Java это массивы массивов, поэтому строки могут иметь разную длину.

```java
int[][] triangle = {
    {1},
    {2, 3},
    {4, 5, 6}
};

for (int row = 0; row < triangle.length; row++) {
    for (int col = 0; col < triangle[row].length; col++) {
        System.out.print(triangle[row][col] + " ");
    }
}
```

Не используйте `matrix[0].length` для всех строк, если массив может быть jagged или пустым.

## Копирование и сравнение

Присваивание копирует ссылку, а не элементы:

```java
int[] original = {1, 2, 3};
int[] alias = original;
alias[0] = 99; // original[0] тоже 99
```

Для копии используйте:

```java
int[] copy1 = original.clone();
int[] copy2 = Arrays.copyOf(original, original.length);
int[] slice = Arrays.copyOfRange(original, 1, 3);
```

Для одномерного содержимого — `Arrays.equals`, для вложенного — `Arrays.deepEquals`. `==` проверяет, одна ли это ссылка.

## Полезные операции `Arrays`

```java
Arrays.sort(scores);
int position = Arrays.binarySearch(scores, 10); // массив должен быть отсортирован
Arrays.fill(scores, -1);
String text = Arrays.toString(scores);
```

`binarySearch` возвращает отрицательное значение, если элемент не найден; оно кодирует insertion point. Не воспринимайте любое отрицательное значение как допустимый индекс.

## Массивы и generics

Массивы covariant: `String[]` является `Object[]`. Ошибка несовместимой записи обнаруживается во время выполнения:

```java
Object[] values = new String[1];
values[0] = 42; // ArrayStoreException
```

Generics invariant и ловят аналогичную проблему на этапе компиляции. Создать `new T[]` напрямую нельзя из-за type erasure; обычно передают фабрику/`Class<T>` или используют collection.

## Передача в метод

Java передаёт значение ссылки. Метод может менять элементы, но переназначение параметра не заменяет массив вызывающего кода.

```java
static void change(int[] values) {
    values[0] = 7;       // видно снаружи
    values = new int[5]; // локальное переназначение
}
```

Если метод не должен менять вход, документируйте контракт и при необходимости копируйте массив.

## Complexity

| Операция | Время |
|---|---:|
| Доступ/запись по индексу | O(1) |
| Линейный поиск | O(n) |
| Копирование | O(n) |
| Вставка с сохранением порядка | O(n) |
| Сортировка примитивов | обычно O(n log n) |

## Типичные ошибки

- условие `i <= array.length` вместо `i < array.length`;
- сравнение массивов через `==`;
- забытая сортировка перед `binarySearch`;
- shallow copy вложенного массива;
- неявное изменение входного массива в методе;
- выбор массива, когда размер постоянно меняется.

## Практика

1. Разверните массив на месте двумя указателями.
2. Перенесите нули в конец, сохранив порядок остальных элементов.
3. Найдите максимальную сумму непрерывного подмассива.
4. Поверните квадратную матрицу на 90° без второй матрицы.
5. Объясните time/space complexity каждого решения.
