### 1 этап - ветки в Git

1) Создайте репозиторий в Github с базовой структурой проекта
2) Создайте ветку 'feature/task-1'. Напишите в ней `System.out.println("Hello world");`
3) Запушьте код в ветку 'feature/task-1' на github
4) Создайте Pull Request в основную ветку
5) Сделайте Merge Pull Request
6) Переключитесь на ветку main
7) Сделайте git pull
8) Создайте ветку 'feature/task-2'. Напишите в ней `System.out.println("Hello world from task 2");`
9) Запушьте код в ветку 'feature/task-2' на github
10) Создайте Pull Request в основную ветку
11) Переключитесь на main.
12) Создайте ветку 'feature/task-3'. Напишите в ней `System.out.println("Hello world from task 3");` на той же строке,
    где и в task-2 была написана строка для task-2.
13) Запушьте код в ветку 'feature/task-3' на github
14) Создайте Pull Request в основную ветку
15) Смержите ветку в main
16) Зайдите в PullRequest `feature/task-2` -> `main`. Посмотрите, что там конфликт.
17) Сделайте git pull в main
18) Переключитесь на ветку 'feature/task-2'
19) Сделайте git merge main
20) Разрешите конфликт
21) Запушьте изменения в ветку 'feature/task-2' на github
22) Перейдите в PullRequest `feature/task-2` -> `main`
23) Сделайте Merge Pull Request
24) Переключитесь на main
25) Сделайте git pull
26) Ура, вы все сделали
