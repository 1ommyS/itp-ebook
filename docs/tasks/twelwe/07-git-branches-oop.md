# Практика: ветки Git и ООП

### 1 этап - ветки в Git

1) Создайте репозиторий в Github с базовой структурой проекта <br>
2) Создайте ветку 'feature/task-1'. Напишите в ней `System.out.println("Hello world");` <br>
3) Запушьте код в ветку 'feature/task-1' на github <br>
4) Создайте Pull Request в основную ветку <br>
5) Сделайте Merge Pull Request <br>
6) Переключитесь на ветку main <br>
7) Сделайте git pull <br>
8) Создайте ветку 'feature/task-2'. Напишите в ней `System.out.println("Hello world from task 2");` <br>
9) Запушьте код в ветку 'feature/task-2' на github <br>
10) Создайте Pull Request в основную ветку <br>
11) Переключитесь на main. <br>
12) Создайте ветку 'feature/task-3'. Напишите в ней `System.out.println("Hello world from task 3");` на той же строке, <br>
    где и в task-2 была написана строка для task-2. <br>
13) Запушьте код в ветку 'feature/task-3' на github <br>
14) Создайте Pull Request в основную ветку <br>
15) Смержите ветку в main <br>
16) Зайдите в PullRequest `feature/task-2` -> `main`. Посмотрите, что там конфликт. <br>
17) Сделайте git pull в main <br>
18) Переключитесь на ветку 'feature/task-2' <br>
19) Сделайте git merge main <br>
20) Разрешите конфликт <br>
21) Запушьте изменения в ветку 'feature/task-2' на github <br>
22) Перейдите в PullRequest `feature/task-2` -> `main` <br>
23) Сделайте Merge Pull Request <br>
24) Переключитесь на main <br>
25) Сделайте git pull <br>
26) Ура, вы все сделали <br>

### 2 этап - fork + ДЗ по ООП и StringBuilder
1) Перейдите на [страницу репозитория](https://github.com/1ommyS/dz-oop) <br>
2) Сделайте Fork репозитория <br>
3) Склонируйте репозиторий к себе на компьютер <br>
4) Создайте ветку 'homework/surname-name'. Напишите в ней реализаци задач <br>  
5) Запушьте код в ветку 'homework/surname-name' на github <br>
6) Создайте Pull Request в основную ветку <br>
7) Отправьте ссылку на PullRequest в чат <br>
